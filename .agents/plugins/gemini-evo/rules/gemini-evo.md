# EVO Gemini MCP Integration Rules

When assisting with the EVO Personal AI Operating System, you have access to the `gemini-evo` MCP server tools:

- `evo_get_dashboard`: Inspect user's performance score, active priorities, and streak metrics.
- `evo_list_tasks`: Check active tasks and priorities.
- `evo_create_task`: Add a high-leverage task to the planner.
- `evo_toggle_task`: Mark a task complete or revert to todo.
- `evo_list_goals` & `evo_create_goal`: Check or set multi-year vision goals.
- `evo_list_habits` & `evo_toggle_habit`: Check daily habit streaks (e.g. DSA, Java study, Workout).
- `evo_get_finance_summary` & `evo_log_expense`: Audit savings pace, discretionary spending, and net surplus.
- `evo_get_memories` & `evo_add_memory`: Recall and store user preferences and lessons.
- `evo_consult_ai_coach`: Generate an optimized execution protocol based on current goals.
